恢复备份中的待办

一条通知，三步收好

  1. 粘贴通知，选对发送日期

    一次整理一件事。“明天”“下周”等说法，都按通知发送日期计算。

  2. 核对草稿，再保存

    检查事项、日期、时间和要求。遇到多个日期或含糊的表述，请手动确认。

  3. 做完勾选，定期备份

    待办会保存在本机。需要提醒时，生成日历文件，再到系统日历中设置。

现在能做什么？

整理文字通知、管理待办、备份恢复。暂不识别图片、PDF 或 Word，不会自动同步或发送提醒。
