电脑、手机，接着用

每个设备单独保存数据，不会自动同步。

  1. 在原设备导出数据

    保存一份 JSON 备份文件。

  2. 把文件传到另一台设备

    可通过聊天软件、文件传输或隔空投送。

  3. 在另一台设备导入

    用浏览器打开同一个网址，选择备份文件。可合并记录，也可替换全部。

清理浏览器数据会删除记录，建议定期导出。主屏幕应用和浏览器有时使用不同存储，也请用备份搬家。

导入待办

像小软件一样打开

  1. iPhone / iPad

    用 Safari 打开网址，点“分享”，选择“添加到主屏幕”。

  2. 安卓手机

    用支持安装的浏览器打开网址，在菜单中选择“安装应用”或“添加到主屏幕”。不同浏览器名称可能不同。

  3. 电脑

    使用 Edge 或 Chrome，点击地址栏安装图标，或在浏览器菜单中安装此网站。

首次联网打开并完成缓存后，可离线使用。聊天软件内置浏览器可能不支持安装，请复制网址到系统浏览器。本地 HTML 文件不能安装。

一条通知，三步收好

  1. 粘贴通知

    每次放入一件事，并选对通知发送日期。

  2. 核对日期和要求

    基础规则只能提供草稿。多日期通知、跨年或不明确的时刻需要手动确认。

  3. 保存，或导出日历

    待办保存在当前浏览器；清理浏览器数据会丢失记录，建议定期备份。导出的时间按日历本地时区理解，提醒请在日历中设置。
