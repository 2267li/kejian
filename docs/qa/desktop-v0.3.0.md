# Windows 0.3.0 验证记录

日期：2026-10-13。范围仅 Windows 桌面版，使用本机 Windows x64 和已安装的 WebView2 Runtime。原网站和微信小程序本轮没有修改、测试或发布。

## 结果

- `pnpm run check:desktop` 通过，检查桌面交互、桥接、构建和 EXE 测试脚本。
- `pnpm run test:core` 的 56 项测试全部通过，包含 40 条模拟通知、6 条注明来源的公开通知摘编及日期/日历基础测试。
- `pnpm run build:desktop` 生成单 EXE 和完整 ZIP；验证资源齐备、脚本语法、版本信息和包内文件摘要。
- `pnpm run test:desktop` 在独立中文路径启动真实 EXE 完成回归。测试复制的程序和最终发行 EXE 摘要一致。
- EXE：983,040 字节，SHA-256 `997d5b268e86637151de95daccc146e46ec9ec5e470b813ea067ef289c764dc5`。
- ZIP SHA-256：`b66b4b935c3ac9bfa3b1924769ae52d03bec99be591afb02ddaa04c8679ae210`。
