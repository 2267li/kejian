# 产品说明

## 定位

课间：面向大学生的通知转待办工具。先验证“粘贴通知、核对、保存”是否能省事。电脑和手机均通过网址使用，可添加到桌面。

零付费 API。AI 辅助开发；实际提取是本地规则，不是大模型理解。

## 已实现

- 单条文字通知、发送日期、标题/常见日期时间/分类/要求草稿。
- 多日期、缺失年份等提示用户核对，编辑后保存。
- 原通知查看、完成与恢复、删除与撤销、ICS 日历导出。
- 响应式网页、手机底部导航、安装指引、首次缓存后离线运行。
- JSON 导出与导入：默认合并，同 ID 采用导入数据；替换全部需要确认。
- 用户主动复制反馈，失败时下载文本，不自动发送。

未实现：截图识别、自动读取聊天、批量通知、后台推送、账号、自动跨设备同步、统计分析、收费功能。

## 数据与隐私

通知 → core.js 本机规则提取 → 用户核对 → app.js 写入 localStorage。
存储键 kejian-notice-tasks-v1。备份格式与 0.1 兼容；清理浏览器数据前先备份。

同源页面共享存储，不同设备、浏览器、网址分别保存。主屏幕应用与浏览器可能使用不同存储，必要时手动导入导出。无痕模式不适合长期保存。

网页及更新需下载静态文件，托管平台处理正常网站访问。应用不主动上传通知或待办，不含外部字体、统计 SDK 或 API。Service Worker 只缓存应用文件。

## 日期与提醒

相对日期按通知发送日期。缺失年份按通知年份并提示跨年。多日期不猜截止时间。ICS 有时刻事件使用本地浮动时间，无时刻事件为全天事件；导入日历后检查时区与提醒。

## 试用

线上试用链接确认可访问后用于 B站、小红书发布。让用户直接反馈遇到的具体问题；点赞不代表留存。产品不会自动收集反馈，需贴回发布帖。

费用和部署信息见 development.md 与 deployment.md。移动端自动化不代表已完成真机安装验证。
