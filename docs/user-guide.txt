电脑与手机网页试用版

在线使用：https://kejian-notice-todo.lih2267194.chatgpt.site

打开与安装
电脑或手机浏览器打开发布帖中的课间网址。
首次联网打开，等页尾出现“已就绪 · 断网也能用”，之后可离线使用。
iPhone / iPad：Safari → 分享 → 添加到主屏幕。
安卓：在支持安装的浏览器菜单中选择“安装应用”或“添加到主屏幕”。
电脑：Edge / Chrome 地址栏安装图标，或网页上的“添加到桌面”。
浏览器名称和菜单可能不同，聊天软件内可复制网址到系统浏览器。
本地 HTML 是电脑离线备用版，不能安装为主屏幕应用。

开始使用
1. 点击“实验作业”示例，或粘贴一条通知。
2. 选对通知发送日期，“明天”“下周”会以它为准。
3. 整理后核对标题、日期、时间和要求，再保存。
4. 手机上用底部导航切换“收通知”和“我的待办”。
5. 完成后勾选；日历文件可导入日历应用，再自行设置提醒。

电脑与手机之间搬数据
在原设备点击“导出数据”，得到 JSON 文件。
通过文件传输、聊天软件或隔空投送，把文件传到另一台设备。
在新设备打开相同网址，点“导入数据”，选中 JSON 文件。
手机也可以从底部“数据与帮助”进入。
默认合并：保留本机记录；相同 ID 以文件中的内容为准，可能覆盖本机更新的编辑。
重复导入同一备份不会新增重复 ID。不同 ID 但标题相同的待办会分别保留。
如果选“替换全部”，会再次确认；建议先导出本机备份。
旧 0.1 版本导出的备份也能导入。
没有账号与自动同步，每次转移后的修改需要重新导出导入。

保存、费用与隐私
免费试用，无需注册或 API 密钥。通知和待办只在本机处理保存。
首次打开和更新会下载网站文件，应用不上传通知或自动收集反馈。
不同浏览器/设备/网址分别保存，清理浏览器数据会丢失记录。
主屏幕应用与浏览器有时使用不同存储，也可用备份搬家。
不要用无痕模式长期保存，请定期备份。

识别与提醒边界
这是基础规则识别，不是大模型理解；每次只整理一件事。
多日期需要自己决定截止时间，跨年或含糊时刻需要手动确认。
暂不支持截图、读取聊天和批量整理。
关闭页面后不会弹提醒；导入日历后检查时间并设置提醒。

更新
看到新版本提示时，先保存正在编辑的内容，再点更新。
已保存待办保留；未保存的表单会随刷新丢失。

反馈
电脑顶部或手机“数据与帮助”里点“说说你的想法”。
复制文字后贴回原发布帖；不允许复制时会下载 TXT。
按钮不会自动给开发者发送消息。建议使用虚构通知反馈问题。
