课间 Windows 桌面版 0.2.1

1. 解压到 E 盘或其他可写入的文件夹，双击“课间.exe”。无需安装，不需要管理员权限。
2. 粘贴通知，核对日期和要求，再保存。断网也能使用。
3. 点击“保存备份”选择文件位置；将备份传到手机后，可在微信小程序中恢复。电脑也能读取小程序和网页版保存的课间备份。各端不会自动同步。
4. 记录保存在课间.exe 旁的“课间数据”文件夹。移动程序、换版本时，请同时保留该文件夹；最好先保存一份备份。不要删除这个文件夹。
5. “数据与帮助”中可打开数据文件夹。日历文件需用支持导入的日历应用打开并设置提醒。

运行环境：Windows 10/11 64 位、.NET Framework 4.7.2 或更新版本、Microsoft Edge WebView2 运行环境。
本次开发电脑已经具有所需运行环境。其他电脑若缺少 WebView2，请从微软官网下载免费运行环境：
https://developer.microsoft.com/microsoft-edge/webview2/
不需要安装 Node、pnpm、Python 或微信开发者工具。

此为免费试用版，尚未购买代码签名证书。Windows 可能显示“未知发布者”；仅运行你确认来源的文件。
通知在本机处理。当前不识别截图、PDF 或 Word 内容，不会自动发送提醒，也不会自动上传或同步待办。
退出时未保存的通知或草稿会提示确认。已保存的待办在下次打开时保留。
