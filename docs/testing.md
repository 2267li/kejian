## v0.2.0 验证结果（2026-10-11）

- 10 项日期和日历边界测试通过：相对日期、跨月跨年、多日期、多时间、非法日期、缺失年份、无日期、中文时刻、ICS 转义折行和全天事件。
- 本地 HTML 离线回归通过：保存刷新、编辑、文字注入安全、完成恢复、删除撤销、日历下载、导出导入、多日期提示、帮助及反馈下载。
- PWA 应用文件、manifest 与 PNG 图标可访问；Service Worker 成功控制页面并完成缓存。
- Chromium 安装条件检查只返回测试隔离环境的 in-incognito 限制，没有其他条件错误。该检查不等于实际完成系统安装。
- 两个独立浏览器上下文模拟电脑和手机，验证数据隔离、电脑导出到手机、手机编辑后导回电脑。
- 默认合并保留已有待办、重复导入按 ID 去重、无效文件拒绝、替换取消和确认均通过。
- 手机断网后重新加载页面，记录仍在；完成状态可保存，离线可新增待办。
- 手机导航、编辑表单切换、使用说明、安装指引正常；输入字号为 16px。
- 360、390、700、768、1440 像素视口无水平溢出。已检查桌面及手机截图。
- 两套浏览器流程中页面脚本错误 0、第三方 HTTP 请求 0；PWA 的本机静态文件请求属于预期行为。
- 公开部署后用全新、未登录的 Edge 上下文，以手机尺寸打开正式 HTTPS 网址：HTTP 200，新增待办后断网刷新仍可看到记录，离线状态正常，页面脚本错误 0。这不代表所有地区网络或真机已经验证。

测试截图位于 .cache/previews，确认的展示图放在 assets/previews。模拟数据不会打包进软件。
