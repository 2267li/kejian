课间 · 微信小程序开发版 0.1.0

本包是开发源码，尚未公开发布；不能将 ZIP 当作已上线小程序分享给用户。

在这台电脑开发：
1. 打开微信开发者工具，导入 E:\Project\kejian（包含 project.config.json 的目录）。
2. 当前配置 touristappid 仅用于测试；没有专属 AppID 时，可按工具提供的测试号/不使用云服务方式检查项目。实际权限以开发者工具为准。
3. 注册自己的小程序后，在 project.config.json 的 appid 填入自己的 wx 开头 AppID。AppSecret 不写入客户端，不发给他人。
4. 编译查看“收通知”“我的待办”“数据与帮助”。本项目不需要云开发环境，不用 npm 构建，不需要服务器域名。
5. 调试基础库固定为 3.12.1，已在本机 1.06.2308310 工具中完成模拟器验证；不要随意改回 latest。本机工程可运行 pnpm run wechat:open，自动检查工具数据实际位于 E 盘。

使用此 ZIP：
解压到一个单独目录，在开发者工具中导入包含 project.config.json 的那一层。当前 miniprogram 目录已经包含同步好的识别逻辑。

注册与发布：
登录 https://mp.weixin.qq.com ，注册类型选“小程序”，主体选“个人”。开发者账号不等于具体小程序账号；需要在小程序后台取得 AppID。
按实际功能选择允许的工具类目，完成主体认证、小程序备案和隐私保护信息配置。费用和材料以微信后台为准。
真机验证后，先上传为体验版；确认可用、资料齐全，再提交审核，审核通过后发布。当前没有执行上传、提审、购买或广告接入。

功能：
粘贴文本通知 → 规则识别 → 人工核对 → 保存待办；支持完成/恢复、编辑、删除、原通知查看、JSON 备份合并/替换、ICS 日历文件导出。

数据迁移：
网页版导出 JSON，通过微信发给自己，在小程序“数据与帮助”选择聊天里的备份文件。小程序导出的 JSON 可回到网页版导入。
无法转发文件时可复制 JSON 备份，在小程序粘贴导入；文件选择与分享能力仍需用你的实际微信版本验证。
数据只保存在本机，不自动同步。小程序测试配置换成正式 AppID 后，本地数据也不会自动迁移，请先备份。
本机记录按 UTF-8 字节数限制在 950 KiB 以内，给微信单项 1 MB 缓存限制留余量。大量长通知可能先达到容量限制，导入失败不会替换已有记录。

当前不支持：
图片/PDF/Word 内容识别、自动读取群聊、自动云同步、后台推送提醒、会员支付或广告收益。
